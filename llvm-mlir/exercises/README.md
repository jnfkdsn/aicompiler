# MLIR 动手练习

这里保存学习者来完成的任务。原理章节后的问题承担回忆与推演；练习在这个基础上增加实际修改、观察与测试，不再重复一套口头问答。

## 当前从哪里开始

[练习 01：将固定区间的 clamp 简化为常量](./01-clamp-simplify/README.md) 已准备好任务契约、可构建骨架、输入及检查。`Exercise.cpp` 的 TODO 留给你实现，已有 Pass/PatternRewriter 和操作定义知识即可开始。

初始状态：骨架已验证，学习者实现未完成。`--stage starter` 检查工具可运行；`--stage solution` 检查目标行为，未填 TODO 时应失败。通过脚本后仍需解释条件并补一个自己的用例。

## 示例与练习的区别

| 入口 | 用途 | 学习者的主要动作 |
|---|---|---|
| `../03-ir-api`—`../06-ir-definition` | 作者提供的完整观察示例，与正文对应 | 预测、运行、看中间状态，查已有实现 |
| 本目录 `exercises/` | 有明确契约、待完成部分及判据的任务 | 先设计、写代码、补用例、解释结果 |
| `../docs/validate_*.py` | 文档维护回归 | 维护者核对源码与正文，通常不是练习入口 |
| workspace `upstream/` | 固定版本的上游源码 | 根据具体问题查证机制 |
| workspace `artifacts/` | 构建、IR 输出与日志 | 对照观察，不编辑生成文件实现功能 |

`01-ir-basics`、`02-pass` 还保留先前个人输入，不迁移或覆盖。后续独立作业集中放在这里，避免与正文参考实现混淆。

## 后续任务怎样递进

| 顺序 | 练习方向 | 开始时机 | 准备状态 |
|---|---|---|---|
| 01 | 修改已有操作的规则，连接字段、替换与测试 | 已学 Pass、Rewrite、Op definition | 任务与骨架已提供 |
| 02 | 定义一个小操作，并为它补充验证或接口 | 读完对应定义章节，完成或讨论 01 后 | 方向已登记，具体任务待生成 |
| 03 | 让自定义表示经过 conversion 到目标表示 | 学习 Dialect Conversion 时 | 方向已登记，具体任务待生成 |

每次只细化当前要做的一项。后续根据实际卡点调整难度，不把所有未来方向都变成现在的门槛。

任务默认提供：问题与前置、输入及目标行为、代码编辑位置、正例/反例、复现命令、产物位置和有限提示。第一轮可复用构建与注册外壳，后续再逐渐增加独立搭建范围。完整答案在你请求时提供；通常先审阅你的方案与实现。
